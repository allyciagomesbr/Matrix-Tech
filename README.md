# Matrix-Tech

Projeto realizado por **Allycia da Silva e Lívia Kethilly**.

O **Matrix-Tech** é um projeto desenvolvido como início dos testes para a criação de um **site de loja virtual**, com foco na venda e gerenciamento de **roupas e perfumes**.

O projeto reúne conhecimentos de diferentes disciplinas, principalmente **Banco de Dados, Programação e Desenvolvimento Web**, buscando integrar essas áreas em uma única aplicação.

Durante o desenvolvimento, trabalhamos na criação de **páginas de cadastro, listagem, edição e exclusão de produtos**, além do gerenciamento de **usuários e administradores**. Também desenvolvemos um **carrinho de compras**, permitindo adicionar produtos, controlar quantidades e calcular o subtotal.

Utilizamos tecnologias como **HTML, CSS, JavaScript/Node.js, Express, Handlebars e Sequelize**, além de um banco de dados para armazenar e gerenciar as informações do sistema.

Também buscamos aplicar conceitos de **responsividade, organização visual, usabilidade e acessibilidade**, tornando as páginas mais fáceis de utilizar em diferentes dispositivos.

O projeto está em fase de desenvolvimento e testes, servindo como uma oportunidade para colocar em prática os conhecimentos adquiridos nas disciplinas e aprimorar a construção de aplicações web completas. :::
